## 3. 失效降级路径

- **arXiv**：主端点 `http://export.arxiv.org/api/query`。失败时按 `SourceError` 记录 warning 并跳过该源，**不影响退出码**；不做『换个镜像站』的自动切换（不替用户决定镜像）。
- **HF Daily Papers**：主端点 `https://huggingface.co/api/daily_papers`。某天无数据（空数组）属正常（节假日 / 索引滞后），记为 0 条并继续。
- 单源异常一律走 `ai_scholar.utils.errors.SourceError`，由编排层记 warning 后继续跑其余源。
