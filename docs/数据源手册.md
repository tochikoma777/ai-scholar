## 1. 实测规模（★ 后续所有体积估算的唯一输入）

口径链条（每一步剩余条数，可审计）：

> arXiv total → arXiv 去版本号去重 → 并集（+HF）→ 领域过滤 → N_enter
> `465` → `465` → `515`（= 465 + 50 − 交集 0） → `230`（领域过滤掉 285）

| 量 | 值 | 口径 |
|---|---|---|
| N_arxiv | 465 | arXiv 当日（cs.AI OR cs.CL OR cs.LG，submittedDate 精确框定 2026-10-20）去版本号去重后的条数（单日，非窗口） |
| N_hf | 50 | HF Daily Papers 当日上榜条数 |
| 两源交集 | 0 | HF 上榜论文里 arXiv id 出现在「当天 arXiv 集合」的条数（★ 不是 id_list 全库回查） |
| 去重并集 U | 515 | `|arXiv ∪ HF|`（未做领域过滤） |
| N_enter | 230 | U 经领域过滤（watchlist 命中，threshold=0.9）**进入系统**的条数 |
| 去重后保留比例 | 0.447 | `N_enter / (N_arxiv + N_hf)`，**不是重叠率**（重叠要看『两源交集』那一行） |

辅助口径：

| 量 | 值 | 说明 |
|---|---|---|
| 领域过滤通过率 | 0.447 | `N_enter / U` |
| 领域过滤掉 | 285 | `U − N_enter`（未命中 watchlist） |
| HF 中来自 arXiv（全库） | 50/50 | 按 arXiv id `id_list` 批量回查**全库**（≠ 当天集合，见『两源交集』） |
| 上榜滞后 | 中位 2 天（最大 112 天，样本 50 条） | HF 上榜日 − arXiv 提交日 |

备注：
- N_hf 与 HF 字段表取自备用端点 `https://hf-mirror.com/api/daily_papers`（官方端点本环境不可达）；其为官方数据的镜像，schema 一致，条数具有代表性，但**镜像可能有滞后**（非实时快照）。
- HF 上榜论文相对其 arXiv 提交日**滞后**中位 2 天（最大 112 天）；上榜论文中 50/50 条能在 arXiv 查到。⇒ 两源必须按 arXiv id 交叉去重，且『今天新发现』只能用 discovery 时间过滤。

## 3. 环境分级结论

| 源 | 分级 | 依据 |
|---|---|---|
| `arxiv` | `always` | 官方开放 API，无需认证；本环境实测可达 |
| `hf_daily_official` | `always` | 官方开放 API，无需认证；本环境实测不可达（网络问题，配镜像可解） |
| `hf_daily_mirror` | `always` | 用户显式指定的备用端点 `https://hf-mirror.com/api/daily_papers`（探测用；schema 与官方一致）；本环境实测可达 |

- `always`：源本身公开可用，本地与 Actions 都采。
- `actions_only`：本地跳过且**不计失败**，只在 `AI_SCHOLAR_ENV=actions` 时采集。
- ★ **不可达 ≠ 分级变化**：availability 描述『源本身是否公开可用』，不是『从某台机器能不能访问』。本地 WSL 连不上官方 HF 是网络问题，配 `hf_base_url`（镜像）即可解，分级仍是 `always`。
- 本文件由**本地（WSL）**生成，`actions_only` 的源需另行在 Actions 验证：`gh workflow run ci.yml`（ci.yml 的 probe job，手动触发，不回写仓库）。

## 4. 失效降级路径

- **arXiv**：主端点 `https://export.arxiv.org/api/query`。失败时按 `SourceError` 记录 warning 并跳过该源，**不影响退出码**；不做『换个镜像站』的自动切换（不替用户决定镜像）。
- **HF Daily Papers**：主端点 `https://huggingface.co/api/daily_papers`。本地不可达是**网络环境问题**（配 `hf_base_url` / `--hf-mirror` 可解），不可达只 warning + 跳过该源，**不计失败、不影响退出码**。某天无数据（空数组）属正常（节假日 / 索引滞后），记为 0 条并继续。
- 单源异常一律走 `ai_scholar.utils.errors.SourceError`，由编排层记 warning 后继续跑其余源。
