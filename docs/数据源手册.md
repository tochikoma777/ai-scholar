## 3. 环境分级结论

| 源 | 分级 | 依据 |
|---|---|---|
| `arxiv` | `always` | 官方开放 API，无需认证；本环境实测可达 |
| `hf_daily_official` | `actions_only` | 官方开放 API，无需认证；**本环境（本地 WSL）实测不可达**；Actions 环境另测（ci.yml 的 probe job，结论见 `docs/开发日志.md`） |
| `hf_daily_mirror` | `always` | 用户显式指定的备用基址 `https://hf-mirror.com`（探测用；schema 与官方一致）；本环境实测可达 |

- `always`：本地与 Actions 都采。
- `actions_only`：本地跳过且**不计失败**，只在 `AI_SCHOLAR_ENV=actions` 时采集。
- 本文件由**本地（WSL）**生成，`actions_only` 的源需另行在 Actions 验证：`gh workflow run ci.yml`（ci.yml 的 probe job，手动触发，不回写仓库）。

## 4. 失效降级路径

- **arXiv**：主端点 `http://export.arxiv.org/api/query`。失败时按 `SourceError` 记录 warning 并跳过该源，**不影响退出码**；不做『换个镜像站』的自动切换（不替用户决定镜像）。
- **HF Daily Papers**：主端点 `https://huggingface.co/api/daily_papers`。某天无数据（空数组）属正常（节假日 / 索引滞后），记为 0 条并继续。
- 单源异常一律走 `ai_scholar.utils.errors.SourceError`，由编排层记 warning 后继续跑其余源。
