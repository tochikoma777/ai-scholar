## 3. L4 范围与硬约束（§7 / §8.5）

- **两类推演必须分开**：
  - **可验证判断**（有量化判据 + 到期日）→ **进记分板**，到期自动验证；
  - **长期趋势洞察**（不可证伪）→ 标「**观点**」，**不进统计**、不计入评分。
- ★ **可证伪性由代码判定**（是否有量化判据 + 到期日），**不得由 LLM 自判**。
- 判据模板：`arxiv_paper_count(direction, threshold)` /
  `entity_mentions(entity, threshold)` / `citation_reach(paper, threshold)`。
- **影响分析**：被引增长（依赖 `signals` 时序快照）、方法采纳（实体提及增长）、
  「开创 vs 跟风」判断；**初期必须诚实标注「样本不足」**。
- **定级校准**：回看 `(tier, 半年后引用)` 的相关性。
- 命令：`predict` / `stats` + 记分板；**不给单一综合分**，客观信号与 LLM 判断分列。
