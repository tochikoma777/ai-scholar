## 3. L3 阶段结论与踩坑

- **三级降级实测有效**：`deepseek-v4-flash` 不支持 `json_schema`（400）→ 自动降 `json_object`；
  降级状态按 `(model, format)` 记忆，后续调用直接跳过 json_schema。
- **记账必须按实际 token**：初版把 max_tokens 保守估算写进 `cost_cny`
  （11 次调用 ¥0.1009，实际 ¥0.0027）；已改为调用后按实际 usage 回填。
- **解析失败 / 输出为空也要记账**：成本已发生，不能漏记（grade / deep_analysis 均已修）。
- **`--force` 要覆盖所有幂等跳过**：初版只对关联解读生效，论文增强仍被跳过。
- **正文抓取命中率高**：`arxiv.org/html` 抽样 20/20（22k–243k 字符）；
  单篇 404 是「该论文无 HTML」。长文改**中间省略**（保开头 + 实验/结论），上限 100000；
  下限 2000 丢弃元数据占位页。
- **ar5iv 实测否决**：对有/无 HTML 的论文都只返回约 5k 的 arXiv **摘要页**，不是正文；
  错误回退会伪装成真数据（已写入 `collectors/fulltext.py` 与 `docs/经验固化.md` D1）。
