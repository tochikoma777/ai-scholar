★ 三条最容易再犯的错（L7 全踩过，已修）：
1. **顺序**：`export` 必须在**选篇之前**消费 `data/analyses/` 与 `data/wanted.jsonl`，
   否则"分析过了 / 点读了，但导不出"。
2. **静默跳过**：arXiv `id_list` 对不存在的 id 静默跳过；`wanted.jsonl` 坏行曾会静默丢弃
   ⇒ 未命中 / 坏行**必须**进 `degraded`。
3. **字符串包含式断言**：`f"content_hash: {h}" in text` 被 YAML 引号坑死（红线 18 第 4 次）
   ⇒ 解析用 `parse_frontmatter`。

## 5. 复现命令

```bash
uv sync && uv run alembic upgrade head
uv run pytest -m "not live" -q                # 341 passed（离线）
uv run ruff check . && uv run ruff format --check . && uv run mypy src/ai_scholar
uv run ai-scholar analyze --check              # public 真源是否齐备（零 LLM）
uv run ai-scholar analyze --limit 0            # 只做「db 已有分析 → 补写真源」自愈，零花费
uv run ai-scholar collect --classics --dry-run # 经典清单直采（dry-run 不写库）
uv run python scripts/probe_classics.py        # 清单 id → 标题实测核对
uv run ai-scholar site --out /tmp/site && grep -c 'class="want"' /tmp/site/index.html
```

## 6. 成本

- L7 新增的**自动**开销只有 Actions 的 `analyze`：**off 档 ¥0**；开启后 ≈ ¥0.12/天（¥3.6/月），
  受 `deep_analysis.weekly_limit=5` 与 `budget.daily_limit_cny=2.0` 双重约束。
- `collect --classics`：每天 1 个 arXiv 请求（限速 1/3s），零 LLM、零费用。
- `analyze --check` / `--limit 0` / `want` / `site`：**零 LLM、零网络**。
